# slotraft

Slot lightweight raft statistics from stdin samples.

**Site:** https://theworker02.github.io/slotraft/

## Install / run

```bash
git clone https://github.com/theworker02/slotraft.git
cd slotraft
node src/cli.js
node --test
```
